## Self-Assesment and Skill Development
I believe I succeeded in
I successfully implemented the main features of the Movie App, including fetching data from an API, displaying results dynamically, storing previous searches in localStorage, and allowing users to revisit or delete previous searches.

I could improve the app’s design, UI/UX, and error handling, for example when a movie title is invalid or the API returns no results.
The app does not have advanced search filters, categories, or pagination for results.
I have learned a lot about JavaScript, DOM manipulation, API integration, and using localStorage to store data dynamically.
I am still learning best practices for structuring dynamic applications and handling asynchronous API errors in a user-friendly way.
I would give myself a score of 10/10 points – I implemented all the features I set out to do and feel confident about the outcome.

## Information of the application
Movie App is an application that allows users to search for movies using an API and view detailed information about them. It stores previous searches so users can revisit them, and users can also delete individual searches from localStorage.
